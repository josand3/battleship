# Battleship Game

A vanilla JavaScript implementation of the classic Battleship game.

## Features
- 10x10 game boards
- 5 ships: Carrier (5), Battleship (4), Cruiser (3), Submarine (3), Destroyer (2)
- Drag-and-drop ship placement
- AI opponent with smart targeting
- Visual feedback for hits, misses, and sunken ships

## How to Play
1. Open `index.html` in a web browser
2. Place your ships by dragging from the shipyard to your board
3. Click a ship to rotate it
4. Click "Start Game" when ready
5. Click on the enemy board to attack

## Development
```bash
npm install
npm run lint
```
